# Managing-the-task-list: Техническая документация проекта

## 📋 Обзор проекта

**Managing-the-task-list** — это веб-серверное приложение для управления списком задач (Task Manager), реализованное на Java с использованием фреймворка **Spring Boot** и **Spring Boot DevTools**.

**Основное назначение**: Создание RESTful API для выполнения операций CRUD (Create, Read, Update, Delete) над задачами.

**Текущий статус**: Проект находится на начальной стадии разработки с 6 коммитами в истории.

---

## 🏗️ Архитектура и структура проекта

Проект следует стандартной структуре Spring Boot приложения с использованием Maven в качестве системы сборки.

### Технологический стек:
- **Язык программирования**: Java (100% кода)
- **Фреймворк**: Spring Boot
- **Инструменты**: Spring Boot DevTools
- **Система сборки**: Maven
- **Управление зависимостями**: Maven Wrapper (mvnw)

### Структура каталогов:
```
Managing-the-task-list/
├── .mvn/wrapper/           # Файлы Maven Wrapper
├── src/                    # Исходный код приложения
├── test/                   # Тесты (временно удалены)
├── .gitattributes          # Настройки Git
├── .gitignore             # Игнорируемые файлы Git
├── mvnw                   # Maven Wrapper для Unix-систем
├── mvnw.cmd               # Maven Wrapper для Windows
└── pom.xml                # Конфигурация Maven проекта
```

## 🔧 Установка и запуск

### Предварительные требования:
1. **Java JDK** (версия, указанная в pom.xml)
2. **Git** для клонирования репозитория
3. **Maven** (или используйте встроенный Maven Wrapper)

### Шаги для запуска:
1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/DaniilPobeda1828/Managing-the-task-list.git
   ```

2. **Перейдите в директорию проекта**:
   ```bash
   cd Managing-the-task-list
   ```

3. **Запустите приложение**:
   - С использованием Maven Wrapper:
     ```bash
     ./mvnw spring-boot:run     # Для Unix-систем
     ```
     или
     ```bash
     mvnw.cmd spring-boot:run   # Для Windows
     ```
   - Или соберите и запустите через Maven:
     ```bash
     mvn clean install
     mvn spring-boot:run
     ```

4. **Проверьте работу приложения**:
   После успешного запуска сервер будет доступен по адресу: `http://localhost:8080`

## 🎯 Функциональные возможности API

### Модель данных "Задача" (Task):
```java
public class Task {
    private UUID id;            // Уникальный идентификатор
    private String title;       // Название задачи
    private String description; // Подробное описание
    private boolean completed;  // Статус выполнения
}
```

### Доступные REST эндпоинты:

| Метод | URL | Описание | Тело запроса |
|-------|-----|----------|--------------|
| **GET** | `/tasks` | Получить список всех задач | Не требуется |
| **GET** | `/tasks/{id}` | Получить задачу по ID | Не требуется |
| **POST** | `/tasks` | Создать новую задачу | JSON объекта Task |
| **PUT** | `/tasks/{id}` | Обновить существующую задачу | JSON объекта Task |
| **DELETE** | `/tasks/{id}` | Удалить задачу по ID | Не требуется |

### Примеры запросов:

1. **Создание задачи** (POST `/tasks`):
   ```json
   {
     "title": "Изучить Spring Boot",
     "description": "Освоить основы Spring Boot",
     "completed": false
   }
   ```

2. **Ответ при успешном создании**:
   ```json
   {
     "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
     "title": "Изучить Spring Boot",
     "description": "Освоить основы Spring Boot",
     "completed": false
   }
   ```
